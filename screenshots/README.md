# PRODIGY_CS_04 - Screenshots

Place your application screenshots in this folder.

Expected files:
- `main_interface.png` — the main application window on launch
- `logging_demo.png`    — live logging in action with real key events
- `exported_log.png`    — example of an exported log report

To generate them:

1. Run the app:    python keyboard_activity_monitor.py
2. Main window:    press 'Start Logging', type a few keys, screenshot.
3. Stop logging with 'Stop Logging'.
4. Press 'Export Log', save the report, open it and screenshot the text.

(On Windows, use Win+Shift+S to capture a region; on macOS Cmd+Shift+4;
 on Linux use your desktop's screenshot tool.)
